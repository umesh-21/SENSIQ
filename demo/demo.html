Practice fields

Each one is a different kind of text box, so you can see that detection works in all of them.

What to try

  1. Put a sample in the message box. After half a second a red or amber badge shows the number of findings.
  2. Click the badge. The panel lists each item with its safe replacement.
  3. Click Replace on one item, or Replace all. The text in the box changes and the badge clears.
  4. Try Ignore on a name, then type it again: it stays quiet for this session.
  5. Paste the clean sample: no badge should appear.
